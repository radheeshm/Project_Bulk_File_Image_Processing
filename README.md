# AKASH TECH SOLUTIONS — Project Bulk Image Processing

Professional Windows desktop batch image-processing application built with Python, Tkinter and Pillow.

## Features
- JPG / JPEG / PNG / WEBP input
- Add multiple files or a complete folder
- Resize while maintaining aspect ratio
- JPG / PNG / WEBP conversion
- Quality control
- Original or sequential file naming
- Filename prefix
- Skip smaller images
- Overwrite protection
- Progress tracking
- Processing summary
- ZIP delivery package
- Maximized professional desktop interface
- Green/black AKASH TECH SOLUTIONS branding

## Run from source

```powershell
python -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt
venv\Scripts\python.exe app.py
```

## Build Windows EXE

Run:

```text
build_exe.bat
```

Or manually:

```powershell
venv\Scripts\python.exe -m pip install -r requirements-dev.txt
venv\Scripts\python.exe -m PyInstaller --noconsole --onefile --clean --name "AKASH_Bulk_Image_Processing" app.py
```

Final executable:

```text
dist\AKASH_Bulk_Image_Processing.exe
```
